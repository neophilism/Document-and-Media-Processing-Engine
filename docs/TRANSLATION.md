# Local translation adapter (checkpoint)

`./translation` exports `createLocalTranslationAdapter`. The trusted host supplies a local translator callback, fixed id/version/model SHA256 and explicit language pairs. Invocation requires a clean, strictly authorized exact-byte UTF8 source, declared source/target languages and a processing purpose. Source/output are bounded to 64 KiB; output can have a lower caller limit. Deadlines (10–30000 ms) and abort signals fence late/noncooperative results; exceptions are sanitized. The callback receives only literal source text, language pair and output budget, not source IDs, context or credentials.

The private derivative binds original source revision/hash, decoded source text hash, output text/hash, declared languages, translator/model identity, purpose and profile. Its stable hash excludes creation time and operational timeout. No confidence, sentence alignment, source-language detection or speaker identity is invented. Model wording is unverified and must remain separate from original evidence and factual conclusions.

This is a reusable execution boundary, not a bundled model or proof of translation quality. The host must verify model files, authorization, costs and isolation. Calling it local is a deployment contract, not a network sandbox: arbitrary host callbacks can perform I/O, retain text, ignore cancellation or use an incorrectly declared model. The adapter stops awaiting such work and never accepts late results; it cannot terminate a hostile callback or erase its side effects. Production requires a separately qualified isolated local worker. No network/provider call, model download, real input or paid infrastructure is used by tests.

Checkpoint tests exercise exact provenance, admission-before-execution, untrusted output, deadlines and input/manifest snapshots using a tiny deterministic local translator. They are not linguistic/model acceptance. Final source review, expanded cancellation tests and CI remain pending. DMP-004 remains partial; speech recognition, real model deployment, durable workers and quality/cost evaluation remain pending.
