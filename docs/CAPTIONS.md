# Private timed-caption import

The opt-in `./captions` export imports a restricted literal WebVTT timing/block profile into source-bound caption derivatives. This enables review of supplied transcripts alongside their media edition without claiming to have run speech recognition. The authenticated host supplies a clean purpose-authorized caption evidence record, exact bytes/hash, and a separately authorized media reference, digest and duration. These fields are trusted gateway inputs, not authentication; never accept intake-form booleans as grants. The media bytes are not read or independently verified by this adapter.

The profile requires an optional UTF-8 BOM, exact `WEBVTT` header, a blank line, and one or more cue blocks. Cues may have unique nonempty IDs of at most 128 characters. Timing accepts `MM:SS.mmm` or `HH:MM:SS.mmm` (2-6 hour digits); minutes and seconds are 00-59. No cue layout settings, header metadata, NOTE/STYLE/REGION blocks, SRT or browser rendering semantics are supported. Unsupported or malformed blocks fail; none are silently skipped. Missing separators that introduce another timing delimiter inside a payload fail closed. This is not a general WebVTT conformance validator.

Payloads remain literal untrusted text, including voice tags, markup and entity strings. No DOM is built, entities decoded, speaker identity inferred or confidence invented. Display through text nodes, never `innerHTML`. Normalized derivative text joins payload lines with LF; exact original UTF-8 byte spans retain identifiers, timing and payload with original BOM/newline/Unicode offsets. Ranges are half-open `[sourceByteStart, sourceByteEnd)` into the original caption bytes and exclude the final payload line terminator. Preserve the original source bytes; a derivative cannot reconstruct their exact encoding/newlines by itself.

Inputs are bounded to 5 MiB, 100000 lines, 10000 cues and 10000 text characters per cue. Start times must be nondecreasing; overlapping cues are retained rather than flattened. End times must exceed starts and stay within the supplied positive safe-integer media duration. Every derivative retains exact caption/media revisions and hashes, processor version and creation time. Its content digest includes the normalized cues/anchors and edition bindings but excludes creation time, so re-importing the same editions at another time retains the same digest. The result is private and warns that wording, timing and media association require verification.

Local tests cover BOM, LF/CRLF/CR, Unicode byte offsets, overlaps, literal markup, immutable source/media bindings, authorization/scope/hash rejection, malformed profiles and byte/line/cue limits. No network, model calls, binary media parser, real private caption import, provider credentials or publication is used. Speech recognition, translation, broader format support, durable workers and deployment qualification remain pending under DMP-004/005.

Timing/block reference: [W3C WebVTT](https://www.w3.org/TR/webvtt1/). The deliberately restricted import profile is documented above; retaining payload text does not assert browser-rendering equivalence.
